# Test data

- `parity.json` — key sequences and the text the engine produces for them. Generated by
  `eval/export-parity.ts`; replayed by `eval/host-smoke.cjs` (Node) and by the Swift tests
  (JavaScriptCore), which must both reproduce it exactly.
- `lm-cases.json` — sentences whose outcome depends on the language model reading the context; typed
  through the real model by the Swift tests.
- `lm-fixtures.json` — token ids and scores of the reference model, generated by
  `scripts/lm/convert.py`; the Swift tokenizer and the Core ML model must reproduce them.
- `scenarios/*.txt` — correct English in eight genres (news, articles, academic writing, email, work
  chat, developer notes, instant messages, social posts), dense in what an input method must leave
  alone: names, product names, dates, amounts, versions, paths, commands, contractions, hyphenated
  compounds, British spellings.
- `scenarios/learner.tsv` — word-aligned pairs `level, first language, genre, typed, intended`: what a
  learner of English might type and what they meant. The errors are modelled on well-known patterns
  for each first language; they are not attested learner data.

All files in `scenarios/` were written for this project with the help of language models and are
covered by its licence.
