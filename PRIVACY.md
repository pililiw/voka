# Privacy

Voka works on your Mac and nowhere else.

- **No network.** Voka makes no network connections. The language model is a file inside the
  application and runs on your Mac.
- **Nothing you type is saved.** To choose candidates, Voka reads the word being typed and, when the
  application provides it, up to 90 characters before the caret and one after. This text is used in
  memory, where some of it is kept while Voka runs so that typing stays fast. It is never written to
  disk.
- **Password fields.** When macOS reports Secure Event Input, Voka steps aside: it does not process
  the keys and shows no candidates.
- **Settings.** Voka keeps its settings in its macOS preferences.
